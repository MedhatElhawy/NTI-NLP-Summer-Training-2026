# 🤖 Module 6: Hugging Face, LangChain, RAG, & Agentic Systems

This capstone folder covers transformer pipelines, LCEL prompt engineering, function calling, multimodal RAG, and production-ready vector databases.

---

## 📂 Contents

* **`22_huggingface_pipelines_labs.ipynb`**: Practical tasks utilizing Hugging Face pipelines for sentiment analysis, zero-shot ticket routing, and Named Entity Recognition (NER).
* **`23_langchain_lcel_and_tools.ipynb`**: LangChain Expression Language (LCEL), prompt templates, output parsers, and custom tool binding (`@tool`).
* **`25_multimodal_rag_chromadb.ipynb`**: Multimodal RAG pipeline extracting text and images from PDFs, using Vision LLMs for image description, and storing vectors in ChromaDB.
* **`26_rag_resume_qa_script.py` & `27_rag_resume_qa_notebook.ipynb`**: End-to-end RAG pipeline querying a personal resume/CV PDF using Cohere embeddings and chat models.
* **`28_rag_large_document_batching.py`**: Scalable batch-upload script for large textbooks and documents into vector stores.
* **`29_rag_3_pdfs_pipeline.py` & `30_multitask_pdf_rag_gradio.ipynb`**: Multi-source tabbed PDF RAG system featuring segregated category retrievers (Lectures, Books, CV) integrated with a Gradio UI.
