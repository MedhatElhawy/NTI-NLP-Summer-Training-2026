# 📝 Module 2: NLP Foundations & Vectorization Representations

This folder explores text preprocessing pipelines, tokenization, morphological normalization (stemming and lemmatization), and classical statistical vectorization methods.

---

## 📂 Contents

* **`03_nlp_fundamentals_tokenization.ipynb`**: Introduction to basic vocabulary building and word-to-ID tokenization mappings.
* **`04_text_preprocessing_pipeline.ipynb`**: End-to-end preprocessing pipeline combining regex cleaning, stop-word filtering, stemming, and lemmatization.
* **`05_bag_of_words_vectorization.ipynb`**: Implements the Bag of Words (BoW) model using text cleaning and Scikit-Learn's `CountVectorizer`.
* **`06_tfidf_vectorizer_scratch_demo.ipynb`**: Demonstrates TF-IDF vectorization matrices and dataframe mapping.
* **`07_nlp_text_processing_tools_lab.ipynb`**: Lab notebook comparing NLTK, spaCy, and Regex utilities.
* **`08_arabic_stemming_farasa_camel.ipynb`**: Specialized Arabic text processing using ISRIStemmer, Tashaphyne, Farasa, and CAMeL Tools.
* **`09_keras_embedding_layer_lookup.ipynb`**: Explores word embedding lookups, one-hot encoding, and Keras `Embedding` layers.
* **Dataset:** `arabic_english_dataset.csv`
