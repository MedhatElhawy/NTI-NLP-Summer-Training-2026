
# 🏷️ Module 3: Text Classification & Benchmarks

This folder focuses on rule-based filtering, spam detection, and classical/gradient-boosted machine learning benchmarks for text classification.

---

## 📂 Contents

* **`10_rule_based_sentiment_and_spam.ipynb`**: Toy rule-based sentiment classifier and keyword-matching email spam filter.
* **`11_spam_email_text_preprocessing.ipynb`**: SMS/Email spam dataset cleaning and preprocessing workflow.
* **`12_imdb_ml_classifiers_baseline.ipynb`**: Baseline machine learning classifiers on movie review datasets.
* **`13_imdb_lightgbm_svm_benchmarks.ipynb`**: Advanced benchmarks combining TF-IDF extraction with Multinomial Naive Bayes, Linear SVM, and LightGBM classifiers.
* **Dataset:** `email.csv`
