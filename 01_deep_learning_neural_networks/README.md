# 🧠 Module 1: Deep Learning Foundations

This folder covers foundational neural network architectures built from scratch using NumPy as well as baseline classification models implemented with Keras.

---

## 📂 Contents

* **`01_perceptron_and_activations.ipynb`**: Implements a single-layer Perceptron from scratch in NumPy, proves its mathematical failure on non-linearly separable XOR gates, introduces Multi-Layer Perceptrons (MLPs) with backpropagation, and visualizes major activation functions (Sigmoid, Tanh, ReLU, LeakyReLU).
* **`02_ann_classification_baseline.ipynb`**: Trains a baseline Artificial Neural Network (ANN) using TensorFlow/Keras on the Breast Cancer dataset with data scaling and validation splits.
