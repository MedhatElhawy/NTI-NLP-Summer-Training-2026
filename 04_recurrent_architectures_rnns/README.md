# 🔄 Module 4: Recurrent Neural Networks & Word Embeddings

This folder covers distributed word representations (Word2Vec) and sequential deep learning architectures including SimpleRNN, LSTM, and Bidirectional variants.

---

## 📂 Contents

* **`16_gensim_word2vec_and_rnn_tasks.ipynb` & `15_word2vec_rnn_pipeline.ipynb`**: Trains custom Word2Vec models using Gensim and implements sequence classification using SimpleRNN.
* **`17_rnn_embeddings_gensim.ipynb`**: Text sequencing, padding, and Keras RNN integration.
* **`18_imdb_sentiment_rnn_vs_lstm.ipynb`**: IMDB movie review sentiment analysis comparing SimpleRNN, LSTM, and BiLSTM architectures.
* **`19_twitter_sentiment_stacked_bilstm.ipynb`**: Stacked Bidirectional LSTM architectures for Twitter sentiment classification.
* **`20_arabic_sentiment_gru_vs_rnn.ipynb`**: Arabic sentiment classification benchmark comparing GRU and RNN variants.
* **Datasets:** `Arabic Sentiment Analysis.xlsx`
